# Data

This folder is intentionally empty. The dataset is not redistributed here - download it yourself.

**Source:** [American Companies Bankruptcy Prediction](https://www.kaggle.com/datasets/utkarshx27/american-companies-bankruptcy-prediction-dataset) (Kaggle, CC0 Public Domain)

Download the dataset, unzip it, and place the CSV in this folder so the path is exactly:

```
data/american_bankruptcy.csv
```

That is the path the notebook reads in the Data Loading cell. Any other filename or location will fail.

Expected file: 78,682 rows, 21 columns, roughly 11 MB.
